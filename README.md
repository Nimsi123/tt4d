# TT4D: A Pipeline and Dataset for Table Tennis 4D Reconstruction From Monocular Videos

Project page for the ACM Multimedia 2026 paper [TT4D](https://arxiv.org/abs/2605.01234).

Code and dataset release coming soon.

## Website

The site is a static page (`index.html` + `static/`) based on the
[Nerfies](https://github.com/nerfies/nerfies.github.io) template. It is served with GitHub Pages
from the `main` branch root.
